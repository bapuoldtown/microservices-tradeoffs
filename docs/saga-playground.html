5 · Reproduce with real PostgreSQL

Clone the repository and start the isolated lab in WSL2. The API and worker execute against PostgreSQL; the payment provider is still deliberately simulated.

git clone https://github.com/bapuoldtown/microservices-tradeoffs.git
cd microservices-tradeoffs/labs/002-saga-orchestration
docker compose up --build -d
curl http://localhost:8802/health
curl -s -X POST http://localhost:8802/checkouts \
  -H 'content-type: application/json' \
  -d '{"request_key":"rahul-001","fail_mode":"timeout"}'
docker compose logs -f api
# When finished: docker compose down -v
